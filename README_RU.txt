Dorama Avatar LipSync V0.4

Исправления после теста V0.3:
1) исправлена критическая mask Wav2Lip: теперь зануляется НИЖНЯЯ половина masked-face, как ожидает модель;
2) убран огромный квадрат 1.5x вокруг лица — используется компактный face box с небольшими полями;
3) paste-back выполняется только для нижней части лица;
4) добавлено мягкое feather-смешивание сверху и по бокам, чтобы не было прямоугольной заплатки;
5) глаза, волосы и фон остаются из исходного изображения;
6) результат: MP4 H.264 + AAC до 5 секунд в Movies/DoramaAvatar.

Важно: Wav2Lip weights в этой версии используются только для технического некоммерческого теста. Для рабочего монетизируемого канала нужен движок/веса с коммерчески допустимой лицензией.
