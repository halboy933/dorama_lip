Dorama Avatar LipSync V0.1 — технический APK-тест

Цель V0.1: НЕ обещать полноценный lip-sync до проверки телефона. Эта сборка проверяет:
1. Установку APK на Redmi Note 14 Pro.
2. Выбор PNG/JPG и WAV через Android Storage Access Framework.
3. Запуск ONNX Runtime Android на устройстве.
4. Что следующий этап Wav2Lip имеет смысл делать локально.

СБОРКА В GITHUB:
1. Создай пустой репозиторий.
2. Распакуй ZIP и загрузи ВСЁ содержимое в корень репозитория, включая .github.
3. Actions -> Build APK -> Run workflow (либо push сам запустит сборку).
4. Открой завершённый workflow -> Artifacts -> DoramaAvatarLipSync-v0.1-debug.
5. Установи app-debug.apk на телефон.

ТЕСТ:
1. Выбрать PNG/JPG аватара.
2. Выбрать наш 5-секундный WAV.
3. Нажать «Проверить телефон и файлы».
4. Прислать скрин результата.

Почему модель Wav2Lip пока не вложена: сначала проверяем, что APK/ONNX стабильно запускаются именно на телефоне. Это экономит время и не заставляет собирать тяжёлую модель вслепую.
