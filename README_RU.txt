Dorama Avatar LipSync v0.3

Цель: первый настоящий MP4 на Android.
1. Выбрать PNG/JPG.
2. Выбрать WAV PCM 16-bit.
3. Проверить/скачать Wav2Lip ONNX. Если модель уже осталась от V0.2 после обновления приложения, повторная загрузка не нужна.
4. Создать до 5 секунд lip-sync.

V0.3 делает Wav2Lip inference, возвращает 96x96 результат в область лица, кодирует H.264 25 fps, кодирует WAV в AAC и сохраняет MP4 в Movies/DoramaAvatar.

Это тест качества. Публичные Wav2Lip weights не используем для коммерческой публикации/монетизации; после проверки пайплайна переходим на движок с подходящей лицензией.
